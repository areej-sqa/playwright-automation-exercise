# Playwright Automation — Automation Exercise

A web test automation portfolio built with Playwright and JavaScript, targeting the public demo application [Automation Exercise](https://automationexercise.com/).

## Project Objectives

- Automate real end-to-end user workflows.
- Validate positive and negative scenarios.
- Practice maintainable automation using Page Object Model.
- Cover UI and API testing.
- Validate application behavior through assertions.
- Run automated regression tests and generate reports.

## Planned Test Coverage

### User Account
- User registration
- Login with valid credentials
- Login with invalid credentials
- Logout
- Duplicate email registration
- Contact form validation

### Products and Shopping Cart
- View products
- Search products
- Verify product details
- Add products to cart
- Remove products from cart
- Verify cart totals and quantities

### Checkout
- Complete checkout workflow
- Validate required checkout fields
- Verify order confirmation
- Test relevant negative scenarios

### API Testing
- Verify API responses and status codes
- Validate product and brand endpoints
- Test search and account-related API scenarios where supported

## Technology Stack
